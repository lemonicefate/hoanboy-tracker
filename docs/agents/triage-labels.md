# Triage labels

| Canonical role | GitHub label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Maintainer evaluation required |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Human implementation required |
| wontfix | wontfix | Will not be implemented |

Use these exact strings when skills refer to triage roles. Check existing labels before creating missing ones; preserve unrelated labels.
